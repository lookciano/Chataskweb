Política de Privacidade — Chat Task

Última atualização: 2 de agosto de 2026

O aplicativo Chat Task ("nós", "aplicativo") é um aplicativo de comunicação e gestão de tarefas desenvolvido para equipes de engenharia. Esta política descreve como coletamos, usamos e protegemos suas informações.

1. Dados que coletamos

Para utilizar o Chat Task, coletamos os seguintes dados:

  • Nome e e-mail: utilizados para identificação do usuário no chat e criação de conta.
  • Mensagens de chat: conteúdo das mensagens enviadas nas salas de conversação.
  • Tarefas: descrição, status, prazo e responsável das tarefas criadas.
  • Participação em salas: registro de quais salas o usuário participa.

2. Como usamos seus dados

Os dados coletados são utilizados exclusivamente para:

  • Identificar o usuário nas mensagens e tarefas do chat.
  • Permitir a comunicação entre membros da equipe em salas privadas.
  • Organizar e atribuir tarefas dentro da equipe.
  • Processar comandos de inteligência artificial (extração de tarefas e resumos) quando solicitado pelo usuário.

3. Compartilhamento de dados

Não compartilhamos seus dados com terceiros. Os dados são acessíveis apenas entre os membros das salas das quais você participa. O acesso é controlado por convite — somente usuários convidados podem entrar em uma sala.

4. Inteligência Artificial (IA)

O Chat Task utiliza processamento de IA para extrair tarefas de mensagens e gerar resumos. O conteúdo das mensagens pode ser enviado a um provedor de IA (OpenRouter) para esse processamento, exclusivamente quando o usuário solicita essa funcionalidade. Os dados não são armazenados pelo provedor de IA além do necessário para processar a requisição.

5. Segurança dos dados

  • Todas as comunicações são criptografadas via HTTPS (TLS).
  • As senhas e sessões são protegidas com tokens assinados (JWT).
  • O banco de dados é hospedado em infraestrutura cloud com acesso restrito.
  • Cada usuário só pode acessar salas das quais é membro explicitamente.

6. Retenção e exclusão de dados

Seus dados são mantidos enquanto sua conta estiver ativa. Você pode solicitar a exclusão de sua conta e dados a qualquer momento enviando um e-mail para luciano.magalhaes@gste.com.br. A exclusão remove o usuário, suas mensagens permanecem no histórico da sala (sem identificação pessoal), e as tarefas atribuídas a ele são reabertas.

7. Acesso e controle

Você tem o direito de:

  • Saber quais dados seus estão armazenados.
  • Solicitar a correção de dados incorretos.
  • Solicitar a exclusão de seus dados.
  • Sair de qualquer sala a qualquer momento.

8. Crianças

O Chat Task não é direcionado a crianças e não coleta dados de menores de 18 anos.

9. Alterações nesta política

Esta política pode ser atualizada periodicamente. A data da última atualização está indicada no topo desta página.

10. Contato

Para questões sobre privacidade ou solicitação de exclusão de dados, entre em contato:
